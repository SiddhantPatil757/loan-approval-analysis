📊 3. CIBIL Score → Risk Category → Approval
SELECT 
    Risk_Category,
    loan_approval_status,
    COUNT(*) AS total
FROM (
    SELECT 
        CASE 
            WHEN CIBIL_Score >= 750 THEN 'Low Risk'
            WHEN CIBIL_Score >= 650 THEN 'Medium Risk'
            ELSE 'High Risk'
        END AS Risk_Category,
        loan_approval_status
    FROM loan_data
) AS sub
GROUP BY Risk_Category, loan_approval_status;
👉 What
Converts CIBIL score into categories
Then checks approval per category
👉 Why

Raw score is messy → categories = better decision making

👉 How to explain

“I derived risk categories using CIBIL score thresholds and analyzed how each category impacts loan approval.”

👉 Insight
Low Risk → mostly approved
High Risk → mostly rejected
👉 Impact

👉 Validates credit policy logic
👉 Core for risk-based lending system
